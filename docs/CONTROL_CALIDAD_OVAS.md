# Control obligatorio para todas las OVAs

Esta lista se aplica antes de entregar cualquier OVA nueva o corregida del repositorio.

## Regla de salida

Antes de cada entrega se debe mostrar al usuario una lista resumida con estado **CUMPLE** o **NO CUMPLE**. Si algún criterio está pendiente, la OVA no puede declararse aprobada ni empaquetarse como versión final.

## Lista mínima

- [ ] Contenido alineado con el módulo y el proyecto docente.
- [ ] Lecturas suficientes, contextualizadas y conectadas con el programa.
- [ ] Ocho etapas por sección, salvo que el diseño pedagógico aprobado establezca expresamente otra cantidad.
- [ ] Navegación libre entre etapas y secciones.
- [ ] Avance únicamente después de respuestas correctas.
- [ ] Distractores plausibles, homogéneos y sin opciones absurdas o evidentemente falsas.
- [ ] Las posiciones visibles de respuestas, relaciones y secuencias se barajan de forma estable por actividad; no existe una posición correcta repetida o un orden que revele la solución.
- [ ] Cada actividad declara y evidencia un nivel de la taxonomía de Bloom coherente con el resultado de aprendizaje del proyecto docente; la progresión debe avanzar desde comprensión hacia aplicación, análisis y evaluación.
- [ ] Variedad de selección única, selección múltiple, relación y ordenamiento.
- [ ] Reinicio funcional sin bloquear la navegación.
- [ ] Una sola insignia por unidad, nunca una insignia por sección.
- [ ] Las secciones no contienen imágenes, medallones, textos, botones ni estilos CSS de insignia; toda su presentación y descarga existe exclusivamente en el catálogo de la unidad.
- [ ] Insignia oculta hasta completar correctamente todas las actividades de todas las secciones de la unidad.
- [ ] Segunda verificación lógica antes de permitir la descarga de la insignia.
- [ ] Interfaz, insignia, botones, iconografía y acentos visuales personalizados con la paleta del programa.
- [ ] Logotipo institucional correctamente encuadrado.
- [ ] Botones uniformes con las OVAs aprobadas y estados de foco visibles.
- [ ] Pantalla completa persistente al abrir y recorrer las secciones.
- [ ] Regreso al catálogo desde cada sección.
- [ ] Funcionamiento adaptable en escritorio, tableta y móvil.
- [ ] Descarga individual de secciones y descarga completa de unidad.
- [ ] Referencias locales y archivos JavaScript sin errores.
- [ ] Paquetes ZIP regenerados después de la validación final.
- [ ] Ruta y comando de actualización del servidor incluidos en la entrega.

## Personalización por programa

La paleta, los acentos, la iconografía y la insignia deben derivarse de los recursos aprobados para el programa correspondiente. No se debe reutilizar automáticamente la identidad cromática de otro programa.

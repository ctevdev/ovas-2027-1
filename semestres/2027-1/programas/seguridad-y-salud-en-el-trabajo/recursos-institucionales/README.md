# Recursos institucionales

Recursos gráficos suministrados para conservar la identidad visual del programa y reutilizarlos en sus Objetos Virtuales de Aprendizaje.

## Logotipos

- `logos/ctev-universidad-cartagena.jpeg`: logotipo horizontal del Centro Tecnológico para la Formación Virtual y a Distancia de la Universidad de Cartagena, suministrado el 6 de octubre de 2026.

El logotipo debe mostrarse completo, sin deformación y mediante `object-fit: contain` cuando se ubique dentro de un contenedor de dimensiones controladas.

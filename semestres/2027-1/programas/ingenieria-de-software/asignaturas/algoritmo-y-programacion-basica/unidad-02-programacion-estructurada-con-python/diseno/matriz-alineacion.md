# Matriz de alineación

## Unidad 02

Programación estructurada con Python

**Pregunta problematizadora:** ¿Cómo puedes construir un programa que no solo realice cálculos, sino que tome decisiones y repita acciones de manera controlada sin perder claridad ni posibilidad de verificación?

**RAP2 / RAC:** Diseña e implementa soluciones algorítmicas elementales en Python mediante pensamiento computacional, estructuras básicas y verificación de resultados, utilizando herramientas digitales y de IA de manera crítica y responsable.

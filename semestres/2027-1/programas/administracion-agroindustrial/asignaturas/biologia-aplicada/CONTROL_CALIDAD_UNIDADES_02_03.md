# Lista de control de calidad — Unidades 02 y 03

Fecha de revisión: 14 de octubre de 2026  
Asignatura: Biología Aplicada  
Programa: Administración Agroindustrial

## Resultado general

**APROBADO INTERNAMENTE.** La revisión abarca los dos catálogos, las doce secciones, las noventa y seis actividades y los catorce paquetes descargables.

## 1. Coherencia académica y profundidad

- [x] Cada unidad conserva seis secciones alineadas con el módulo institucional.
- [x] Cada sección desarrolla ocho etapas; no se aceptan secciones abreviadas de cinco etapas.
- [x] Cada etapa incluye lectura de contexto, conexión agroindustrial y actividad verificable.
- [x] Las lecturas tienen una extensión mínima de 145 caracteres y un promedio de 204 caracteres.
- [x] Las conexiones profesionales tienen una extensión mínima de 90 caracteres y un promedio de 145 caracteres.
- [x] Cada sección ofrece al menos cinco referencias para profundización.
- [x] Los casos conectan el concepto biológico con producción, gestión, bioseguridad, sostenibilidad, trazabilidad o innovación.

## 2. Calidad de preguntas y distractores

- [x] Las preguntas de selección tienen tres o más opciones y al menos un distractor.
- [x] Los distractores pertenecen al mismo dominio conceptual que la respuesta correcta.
- [x] Se eliminaron opciones absurdas, humorísticas o descartables por forma, como colores, nombres de formato o afirmaciones sin relación temática.
- [x] Los distractores representan errores plausibles: inferencia causal prematura, generalización, ausencia de controles, extrapolación de escala o uso de un único indicador.
- [x] Las opciones mantienen una longitud y construcción gramatical comparables.
- [x] Las respuestas múltiples conservan correspondencia exacta entre las opciones válidas y los índices de validación.
- [x] No existen opciones duplicadas ni respuestas fuera de rango.
- [x] Se verificaron 198 opciones distribuidas en 34 actividades de selección única y 24 de selección múltiple.

## 3. Variedad de actividades

- [x] Cada una de las doce secciones contiene los cuatro tipos de interacción establecidos.
- [x] Selección única: 34 actividades.
- [x] Selección múltiple: 24 actividades.
- [x] Relación de conceptos: 13 actividades.
- [x] Ordenamiento de procesos: 25 actividades.
- [x] Total validado: 96 actividades.

## 4. Navegación, avance e insignia única de unidad

- [x] Las ocho etapas pueden abrirse en cualquier orden y no funcionan como prerrequisitos.
- [x] Visitar una etapa no incrementa el avance.
- [x] El avance se registra únicamente cuando la respuesta coincide exactamente con la solución definida.
- [x] Las respuestas incorrectas permiten revisar e intentar nuevamente.
- [x] El reinicio elimina el progreso guardado, limpia respuestas y devuelve a la primera etapa.
- [x] Ninguna sección genera o descarga una insignia individual.
- [x] El catálogo consolida el avance de las seis secciones: 48 actividades por unidad.
- [x] Existe una sola insignia por unidad; inicia oculta y solo aparece cuando las seis secciones registran 8 de 8 actividades correctas.
- [x] La función de descarga contiene una segunda verificación de las seis secciones completas; si la condición no se cumple, no genera ni descarga el archivo.
- [x] La insignia conserva el cerebro digital dorado, el valor 100 %, el nombre de la unidad, el programa y el nombre del estudiante.
- [x] El progreso persiste localmente por sección sin mezclar resultados entre OVAs.

## 5. Interfaz y uniformidad visual

- [x] Se recuperó el patrón visual de las OVAs anteriores: cabecera institucional, propósito, panel de avance, línea de tiempo, pantalla de etapa, navegación, insignia y referencias.
- [x] La línea de tiempo presenta ocho posiciones con estados actual, pendiente y completado.
- [x] Todos los botones usan el mismo sistema de tamaño, tipografía, radio, color y estado de foco.
- [x] Los botones mantienen textos uniformes: Volver al catálogo, Reiniciar sección, Validar actividad, Etapa anterior, Etapa siguiente y Descargar insignia SVG.
- [x] Los catálogos mantienen Descargar la unidad completa, Pantalla completa, Abrir sección y Descargar ZIP.
- [x] Se usan Montserrat, logotipo institucional e iconografía individual, no una tira de iconos apilada.
- [x] La interfaz y la insignia están personalizadas con la paleta verde y dorada de Administración Agroindustrial, con contraste, espacio en blanco y longitud de línea controlada.
- [x] La composición responde a escritorio, tableta y móvil mediante puntos de ruptura de 760 y 420 píxeles.
- [x] Los controles interactivos tienen foco visible y etiquetas accesibles.

## 6. Pantalla completa y catálogo

- [x] El control informa mediante `aria-pressed` si la pantalla completa está activa.
- [x] Al abrir una sección desde el catálogo se utiliza el visor interno; no se navega fuera del documento que mantiene la pantalla completa.
- [x] Volver al catálogo cierra el visor sin abandonar la unidad.
- [x] Salir de pantalla completa cierra el visor y termina explícitamente ese modo.
- [x] Si el navegador no admite la API, el botón se oculta sin afectar el resto de la OVA.

## 7. Descargas y paquetes

- [x] Existen seis ZIP de sección y un ZIP de unidad completa por unidad.
- [x] Los dos catálogos resuelven correctamente catorce enlaces de descarga.
- [x] Cada paquete de servidor conserva la estructura desde `semestres/2027-1`.
- [x] Los paquetes de servidor no contienen una copia recursiva de sí mismos.
- [x] Todos los ZIP fueron regenerados después de las correcciones.

## 8. Integridad técnica

- [x] Los 26 archivos JavaScript superan validación sintáctica con `node --check`.
- [x] Los 14 documentos HTML no contienen referencias locales rotas.
- [x] Las 12 estructuras de contenido pueden convertirse desde JSON sin errores.
- [x] Todas las actividades tienen solución válida y controles completos.
- [x] Resultado del auditor interno: cero incumplimientos.
- [x] Resultado del validador de descargas: 2 catálogos y 14 descargas correctas.

## 9. Control obligatorio antes de cada entrega

- [x] La lista de chequeo debe ejecutarse nuevamente después de cualquier modificación.
- [x] Antes de cada salida se debe mostrar al usuario un resumen con estado **CUMPLE** o **NO CUMPLE** para cada grupo de criterios.
- [x] Si existe un criterio pendiente, la entrega no puede declararse aprobada.
- [x] El paquete para servidor solo puede regenerarse después de obtener cero incumplimientos.

## Criterio de cierre

Una unidad solo puede publicarse cuando todos los puntos anteriores permanecen marcados. Cualquier cambio futuro en contenido, estilos, lógica o paquetes obliga a ejecutar nuevamente la auditoría y regenerar los ZIP.
